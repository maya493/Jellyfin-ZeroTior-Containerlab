# Jellyfin-ZeroTier-Containerlab

## Project Overview
This project demonstrates the deployment of a Jellyfin Media Server on a Proxmox Virtual Environment (Proxmox VE). Remote access to the server was configured using ZeroTier, and Containerlab was used to create and test a simple Linux container topology.

## Technologies Used
- Proxmox VE
- Ubuntu Server
- Jellyfin
- ZeroTier
- Containerlab
- Docker

## Project Files
- demo.clab.yml
- Screenshots
- Videos
- Report.pdf
- Presentation.pptx

## Project Workflow
1. Created an Ubuntu Server virtual machine on Proxmox VE.
2. Installed and configured Jellyfin Media Server.
3. Installed and configured ZeroTier for secure remote access.
4. Installed Containerlab and Docker.
5. Created and deployed a Linux container topology using `demo.clab.yml`.
6. Verified connectivity and successful deployment.
